# Checkpoint and recovery card
## Structure
Target card -> current requirement -> adjacent `stuck?` recovery path.
## Recipe
- Use one blue target card with white text.
- Keep the recovery path black on white and action-oriented.
- State a measurable target, not motivational copy.
- On mobile, stack target before recovery.
## Avoid
Progress decoration without a measurable condition, vague encouragement, or success communicated by color alone.
