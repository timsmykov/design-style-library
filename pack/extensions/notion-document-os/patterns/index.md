# Pattern Index — Notion Document OS

## Document page

A page begins with a title, optional icon/cover/meta row, then editable content blocks. Controls are inline and proximity-revealed.

## Workspace shell

Left sidebar contains workspace switcher, favorites/private/teamspaces/page tree, templates/search/settings. Selected rows use pale fills and compact labels.

## Database view

Database chrome sits inside a page: view tabs, filter/sort/search controls, property chips, and a table/board/list body with quiet dividers.

## Template gallery

Cards are use-case starters: title, short description, tiny preview/proof, and one create/duplicate action.

## Command menu

Slash/block menu is a small popover with grouped commands, icons, search, and keyboard selection.

## Marketing proof sections

Public pages use large plain headlines, product screenshots/cards, simple black CTAs, and modular use-case grids.
