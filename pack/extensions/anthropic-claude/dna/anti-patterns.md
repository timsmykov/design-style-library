# Anti-patterns

These break the Anthropic/Claude-inspired system:

## Critical

- Neon gradients, cyber glow, glassmorphism, or glossy 3D SaaS surfaces.
- Robot/brain/laser/futuristic AI clichés as primary identity.
- Bubble-only chat UI with no document/workbench/artifact model.
- Multiple competing primary CTAs in one decision zone.
- Copying Anthropic/Claude logos, exact branded pages, or proprietary layouts as pixel-perfect clones.

## Strong warnings

- Pure sterile white/gray admin UI with no warm editorial character.
- Dense dashboard tables without document-like framing.
- Badge soup: many pills/statuses trying to be first read.
- Oversized nav/header stacks before useful content.
- Clay/terracotta used as a full theme wash instead of sparse accent.
- Hype copy or urgency pressure.
- Decorative artifact cards that do not function as useful work surfaces.
