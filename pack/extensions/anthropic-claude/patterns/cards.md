# Cards Pattern

## Product macro-card

Use for marketing/product sections.

```text
Large rounded card
├── Left: title, concise description, one CTA
└── Right: product proof visual / chat preview / code snippet / artifact demo
```

Rules:

- Large radius: 20–32px.
- Generous padding: 32–56px.
- One message per card.
- Prefer fill contrast over heavy borders.
- Use light cards for user/conversation/productivity use cases.
- Use dark inverse cards for developer/API/code use cases.

## Document/content card

- Warm or white surface.
- Subtle border.
- No heavy shadow.
- Title + compact body + optional metadata/source line.

## Chat/file preview card

- Keep simplified and legible.
- Include file/source chips when relevant.
- User message bubbles may be beige; assistant response cards should read like documents.

## Modal card

- Centered warm off-white surface.
- Dimmed shell overlay.
- Preview/demo area above or beside text.
- Small status pill if needed.
- One primary CTA.
