# Style Pack Contract v0.1

A style pack is a compressed, evidence-backed design operating system for agents.

## Required files

```text
manifest.yaml
STYLE.md
agent-contract.md
evidence/sources.yaml
evidence/observations.yaml
dna/principles.md
dna/layout.md
dna/hierarchy.md
dna/interaction.md
dna/voice.md
dna/anti-patterns.md

tokens/css-vars.css
patterns/index.md
components/component-atlas.md
components/capsules/*.md
components/component-index.jsonl
eval/checklist.yaml
eval/rubric.md
eval/failure-modes.md
```

## Component index build

```bash
tools/component_index.py .
```

This writes:

```text
styles/<style>/components/component-index.jsonl
gbrain_export/components/<style>/<component>.md
```

`gbrain_export/` is generated from repo capsules. Do not hand-edit it as the canonical source.

## Confidence levels

- `observed`: visible in local screenshots/flows/sections.
- `extracted`: measured from HTML/CSS/computed styles/fonts.
- `inferred`: repeated pattern inferred from several evidence items.
- `adapted`: translated into a reusable original system for our use cases.
- `experimental`: promising but not yet proven by golden examples/eval.

## Offline-readiness gate

A pack is `offline_ready: true` only if all are true:

1. The pack has enough local visual evidence for style composition.
2. `STYLE.md` states the canonical style in one sentence and explains when to use/avoid it.
3. Tokens cover color, typography, spacing, radius, border, shadow, semantic roles.
4. Pattern files cover at least three relevant media/components.
5. Anti-patterns are explicit enough to reject generic SaaS output.
6. At least two golden examples or documented equivalent eval artifacts exist.
7. A fresh agent can use the pack without Mobbin/web/browser calls.

## Prompt policy

No `prompts/` directory is part of the canonical contract. Prompts are generated by the agent from:

```text
STYLE.md + relevant dna/*.md + tokens/* + patterns/* + eval/checklist.yaml
```

If a future prompt artifact proves useful, it must be generated output or an eval fixture, not the source of truth.
