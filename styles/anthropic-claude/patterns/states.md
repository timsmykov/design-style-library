# States Pattern

## Empty state

- Sparse canvas.
- One short human sentence.
- Optional tiny friendly/symbolic illustration.
- One primary action or composer.

## Loading / generation

- Calm progress text.
- Avoid theatrical AI-thinking animation.
- Use status chips or subtle skeletons.

## Error / recovery

- Plain language.
- Explain what happened and what the user can do.
- Offer retry/edit/support paths.
- Do not blame the user.

## Publish/share/modals

- Warm rounded modal.
- Clear artifact title/status.
- One primary action.
- Secondary actions stay muted.

## Permission/privacy

- Short explanation.
- Link to privacy/details.
- Ask only for what is needed.
