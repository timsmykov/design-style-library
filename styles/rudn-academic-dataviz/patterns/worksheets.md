# Worksheets and handouts

## Structure

- Start with the question and expected result.
- Separate inputs, steps, evidence fields, and final interpretation.
- Use rules and lightly filled bands, not card decoration.
- Put fixed constraints immediately before the work area.
- Finish with a checklist or definition of done.

## Tables

- Header: lavender or white with bold black labels.
- Active/example cell: electric blue with white text only when projection requires it.
- Body: white, thin gray row rules, consistent unit formatting.
- Do not zebra-stripe unless the table has more than eight rows and lookup accuracy benefits.

## Checklists

Each item uses an icon plus a question. Pair the positive condition with the recovery action: `Same unit? If no, normalize before calculating.`
