# Data visualization

## Chart contract

Every chart includes:

1. Insight-led title.
2. Unit and period.
3. Direct labels or a compact legend.
4. One blue focal series or mark.
5. Neutral comparison marks.
6. Source and method note.

## Palette

- Focal: `#2E6BFE`.
- Comparison: `#697080` or `#B7B7B7`.
- Support/uncertainty: `#DADBF0`.
- Grid: `#E8E8E8`.
- Text: `#272525`.
- Use indigo `#4950BC` for interactive selection, not a competing chart category.

## Chart forms

- Prefer bars for ranking and comparison.
- Prefer lines for time only when there are at least three meaningful points.
- Use dot plots when compact comparison matters.
- Use a table when exact lookup matters more than shape.
- Avoid pies unless there are 2-4 stable parts and exact comparison is not the task.

## Annotation

Use a thin blue rule or blue label connected directly to the mark. Write the meaning, not merely the value: `Transport grew fastest: +18%`.

## Accessibility

Do not rely on color alone. Add direct labels, shapes, line patterns, or explicit text. Keep blue/white and black/white contrast strong; use lavender only behind dark text.
