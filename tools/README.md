# Tools

This directory contains small deterministic helpers for the style library.

Initial tools:

- `stylepack_verify.py` — structural/offline-readiness checks for style packs.
- `remove_mobbin_links.py` — removes live Mobbin URLs while retaining local
  screenshots and evidence metadata.

Planned tools:

- Firecrawl extraction runner;
- Browser/CDP computed-style probe;
- CSS token candidate extractor;
- offline agent-eval runner.
